# Company Intelligence

### AI-Powered Company Research Skill

一个用于企业信息识别、商业分析与结构化情报研究的开源 AI Skill。

Designed by Lexie.

---

## 项目简介

Company Intelligence 是一个基于 Agent Skills
规范设计的企业研究技能。

用户只需输入一家公司的名称，AI 即可根据预设
研究流程，识别企业主体、检索公开资料，并将
结果整理为结构化公司情报报告。

本项目重点关注企业识别准确性、数据来源可靠性
以及输出结果的可追溯性。

## 核心功能

### 1. 企业智能识别

- 识别公司官方名称
- 区分同名企业
- 识别集团、上市主体及子公司
- 识别所属国家和总部所在地

### 2. 商业模式分析

- 主营业务线
- 次要业务线
- 核心产品和服务
- 旗下品牌及产品介绍

### 3. 财务数据研究

- 历年总营业收入
- 年度收入变化
- 财报数据来源
- 财政年度及统计口径

### 4. 中国区经营情况

- 中国大陆员工人数
- 中国区投资项目
- 在华投资金额
- 投资时间及项目进展

### 5. 数据可信度管理

- 官方来源优先
- 数据时间范围标注
- 公司主体消歧
- 缺失数据明确说明
- 避免未经验证的信息推测

## 工作流程

用户输入公司名称
    ↓
公司实体识别
    ↓
判断是否存在歧义
    ↓
检索公开资料
    ↓
核验财务及经营数据
    ↓
生成结构化企业报告

## 使用方法

1. 下载或克隆本仓库。
2. 将 Skill 文件夹导入兼容 Agent Skills
   的 AI 工具。
3. 确保运行环境具有必要的网页检索能力。
4. 输入需要研究的公司名称。

示例：

“请研究 NVIDIA，输出主营业务、历年营收、
旗下产品、中国区员工人数及投资情况。”

注意：

本项目是指令型 Skill，不是独立运行的
企业数据库或爬虫程序。

实际联网检索、文件读取及工具调用能力，
由安装本 Skill 的 AI Agent 运行环境决定。

部分企业未公开披露中国区员工或投资数据，
此类信息将标记为未披露或无法核验。
